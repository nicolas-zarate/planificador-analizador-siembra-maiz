# ¿Como se usan los archivos excels?

Esta carpeta contiene las dos herramientas desarrolladas para el proyecto.

![Demostración](../imagenes/demo.gif)

## 1. Analizador Climático – Campaña 2025/2026

Permite analizar una campaña ya finalizada utilizando datos climáticos reales obtenidos desde Open-Meteo.

### Pasos

1. Abrir el archivo.
2. Ingresar las coordenadas.
3. Completar:
   - Lote
   - Híbrido
   - Fecha de siembra
   - Grados dias a floración, según la cartilla del Híbrido
   - Temperatura base, según la cartilla del Híbrido
4. Darle al botón ACTUALIZA.
5. Analizar el gráfico generado.

---

## 2. Planificador Climático

Permite proyectar una futura campaña utilizando promedios climáticos de los últimos 15 años.

### Pasos

1. Ingresar las coordenadas.
2. Completar con el año de siembra planificado.
3. Completar los datos del cultivo.
4. Darle al botón ACTUALIZA.
5. Analizar la proyección.
